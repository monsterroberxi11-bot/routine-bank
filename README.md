# ⏱️ Routine Bank（ルーティン・バンク）

**朝の支度や宿題のルーチンを、タイマーで「時間貯金」に変えるアプリ。**

目標より早く終わったら、余った時間が貯金になる。貯めた時間は、ゲーム時間やおこづかいと交換できる（親の承認つき）。

👉 **アプリを開く：https://monsterroberxi11-bot.github.io/routine-bank/**

スマホのブラウザで開いて「ホーム画面に追加」すると、ふつうのアプリみたいに使えます。

---

## できること

- ⏱️ **ルーチンタイマー**：「歯みがき3分 → 着替え5分 …」のように動作ごとに進める。声でも案内
- 💰 **時間貯金**：目標より早ければ貯金、オーバーしたら貯金から引く
- 🎁 **交換**：貯めた時間をゲーム時間などに交換。親が4けたのPIN（顔認証も可）で承認
- 🏦 **銀行**：ATMみたいな画面で預け入れ・引き出し。毎週利息がつく
- 🔥 **連続記録**：毎日やると「◯日連続」。5日・10日・20日…でバッジ（土日お休みのオン・オフつき）
- 📊 **分析**：どの動作でよくオーバーするか、理由といっしょに見られる
- 🔔 **通知**：承認待ちやルーチンの時間をお知らせ
- 👨‍👩‍👧 **家族で使える**：親と子どもで役割がちがう。子どもがルーチンを作ると親の承認待ちになる
